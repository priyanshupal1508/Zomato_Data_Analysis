# Zomato_Data_Analysis
Zomato Data Analysis Project
This project focuses on performing end-to-end Exploratory Data Analysis (EDA) on a Zomato restaurant dataset. By leveraging Python's powerful data science libraries, I've transformed raw data into actionable business insights.

Project Overview
I aimed to understand customer behavior and restaurant trends using a dataset containing information on restaurant types, ratings, online ordering patterns, and costs. The project covers the entire pipeline, from data cleaning and preprocessing to statistical visualization.

Key Analysis Questions
To extract value from the data, I addressed the following:

Restaurant Popularity: Which types of restaurants do customers prefer?
Engagement: How do vote counts vary across different restaurant categories?
Sentiment: What is the distribution of customer ratings?
Spending Patterns: What is the average cost for a couple ordering food?
Ordering Modes: Do online orders receive better ratings than offline ones?
Market Strategy: Identifying the relationship between restaurant types and ordering habits.
Libraries Used
Pandas: For data manipulation and cleaning.
NumPy: For numerical operations.
Matplotlib & Seaborn: For generating professional-grade visualizations like histograms, heatmaps, and box plots.
Methodology
Data Cleaning: Handled messy data points (e.g., removing '/5' from ratings) to ensure compatibility for mathematical operations.
Exploratory Data Analysis (EDA): Used statistical methods to identify missing values and validate data integrity.
Visualization: Built interactive plots to translate complex datasets into easy-to-interpret business insights.
Key Findings
Dining Trends: Most customers prefer 'Dining' style restaurants for their experiences.
Rating Sweet Spot: A significant portion of restaurants receive ratings between 3.5 and 4.0.
Cost Sensitivity: Couples typically prefer orders around the 600-currency unit mark, which helps in optimizing app menu suggestions.
Online vs. Offline: Customers show a preference for online ordering when visiting 'Café' style spots, while 'Dining' restaurants still thrive on in-person visits.
